# Experiment 4 — Association Rules with Apriori

**Input:** [`transactions.csv`](transactions.csv). Each row contains one Adult record and a semicolon-separated list of categorical value items plus equal-frequency bins (`Q1`–`Q5`) for numeric attributes. The input is derived from the shared Adult source after categorical missing values are imputed.

The assignment screenshots document the Orange Apriori settings and reported rules (110 itemsets and 113 rules). This CSV contains transaction input only; it does not claim to reproduce Orange's rule output.
