# Dataset source and attribution

This repository uses the Adult Census Income dataset from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/2/adult), cited as Becker and Kohavi (1996), DOI: [10.24432/C5XW20](https://doi.org/10.24432/C5XW20).

- `adult.data` is the 32,561-record training file used in the assignment.
- `adult.names` contains the dataset description and attribute definitions.
- The dataset is distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Please retain attribution when reusing it.
- The original assignment DOCX is intentionally not included. Screenshots are exported separately under `screenshots/`.
