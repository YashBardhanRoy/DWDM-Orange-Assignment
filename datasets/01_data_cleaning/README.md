# Experiment 1 — Data Cleaning

**Input:** [`../adult.data`](../adult.data) (32,561 records).

The report found missing values in `workclass` (1,836), `occupation` (1,843), and `native-country` (583). Orange Impute filled numeric values with the average and categorical values with the most frequent value. The cleaned preview showed no remaining missing values.
