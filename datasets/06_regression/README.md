# Experiment 6 — Regression

The target was `hours-per-week`. Linear Regression, Random Forest (10 trees), and kNN (k=5) were compared with 10-fold cross-validation. The report lists Linear Regression as best: RMSE 11.204, MAE 7.770, R² 0.177.
